# BugWisp Markdown Generator

Generate a professional Markdown security finding from validated finding data using the public BugWisp Markdown template.

Use the template at `.bugwisp/templates/markdown/bug-template.md` when it is available. Preserve the template headings, replace every supported placeholder with the finding value, and use `[N/A]` for optional values that are absent. Keep evidence, reproduction steps, impact, and remediation specific to the supplied finding. Never invent evidence or credentials.
